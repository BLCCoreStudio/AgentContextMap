# Support

AgentContextMap is early-alpha open-source software maintained through GitHub.

## Bugs and incorrect results

Open a GitHub issue using the structured **Bug report** form. For instruction scope or precedence problems, include a minimal repository layout, the target path, the AgentContextMap version, and relevant vendor documentation when available.

## Feature requests

Use the **Feature request** form and describe the concrete workflow the change would improve. The project intentionally prioritizes correctness, explainability, and conservative semantics over broad feature count.

## Security

Do not publish vulnerability exploit details in a public issue. Follow [`SECURITY.md`](SECURITY.md) and use GitHub's private vulnerability reporting surface when available.

## Current support boundary

The published standalone binary and composite GitHub Action currently target Linux x86_64. Building from source may work on other platforms, but platform-specific behavior outside CI coverage should be reported with reproduction details rather than assumed supported.

There is no paid support SLA, account system, hosted backend, or telemetry service.
